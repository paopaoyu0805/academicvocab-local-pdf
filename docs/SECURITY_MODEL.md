# AcademicVocab 安全模型

## 1. 需要保护的内容

- 用户的正式 Zotero 资料库；
- 原始 PDF 和私人论文内容；
- 用户人工创建的 Zotero 标注；
- 生词、例句、翻译、来源和复习历史；
- 腾讯翻译密钥和未来的登录凭据；
- 免费服务额度和用户账单安全。

## 2. 信任边界

### 本地可信区域

- `D:\AcademicVocab` 中经过 Git 记录的项目内容；
- 独立 Zotero 开发 profile 和开发数据；
- 用户在手机或 Zotero 中主动确认的选词操作。

### 有限信任区域

- 手机浏览器；
- 正式 Zotero 及其他第三方插件；
- Supabase 托管服务；
- 腾讯机器翻译。

这些组件只能得到完成自身任务所必需的最少数据。

### 不可信输入

- PDF 中的文字和元数据；
- 用户粘贴或编辑的内容；
- 网络返回值；
- 过期、重复或伪造的同步请求；
- 第三方插件内部对象；
- 客户端声称的额度和所有权信息。

所有不可信输入必须在服务端或插件安全边界内重新验证。

## 3. 主要风险与控制

### PDF 或全文被上传

风险：私人论文内容离开本地设备。

控制：

- 客户端只构造单词和单条例句请求；
- 服务端设置单词 100 字符、例句 2000 字符上限；
- 拒绝文件、Base64、二进制和批量全文；
- 不提供 PDF 上传接口或云存储桶。

### 腾讯密钥泄露

风险：他人盗用额度或产生费用。

控制：

- 密钥只放在未来的 Supabase Edge Function Secrets；
- 客户端只持有用户会话或可撤销设备凭据；
- 日志只记录请求编号、状态、字符数和耗时，不记录密钥或正文；
- 错误响应使用固定错误代码，不返回第三方原始堆栈；
- Git 和构建产物执行密钥形状检查。

### 越权访问其他用户数据

风险：客户端伪造 `user_id`。

控制：

- 用户身份从经验证的会话令牌取得，不相信请求正文中的 `user_id`；
- 所有用户数据表未来开启 Row Level Security；
- 翻译入口验证用户身份；
- Zotero 设备使用短时一次性配对和可撤销凭据；
- `service_role` 永不进入客户端。

### 重复请求浪费额度

风险：断网重试或连续点击产生重复翻译。

控制：

- 每次确认操作使用稳定的唯一请求编号；
- 服务端先检查已经完成的请求和文本缓存；
- 同一个请求只能计费一次；
- 并发重试必须返回同一结果或等待中的状态。

### 免费额度超限

风险：产生费用或翻译服务突然不可用。

控制：

- 腾讯后付费保持关闭；
- 服务端实施每月 500000 字符硬上限；
- 达到上限立即停止外部请求；
- 不自动切换其他付费服务；
- 英文数据照常保存，翻译状态改为 `quota_paused`；
- 用户只能在后续明确阶段手动调整上限。

### 翻译错误覆盖用户修改

风险：后台重试破坏用户已确认内容。

控制：

- 机器翻译和用户修订分开保存；
- 显示时用户修订优先；
- 后台只能更新机器字段；
- 用户字段非空时不得被重译覆盖。

### 外部服务失败

风险：选词流程卡住或生词丢失。

控制：

- 先保存英文单词、例句和来源，再尝试自动翻译；
- 设置请求超时；
- 使用有限次数和延迟增长的重试；
- 长期失败时保留 `pending` 或 `provider_error`；
- 不因翻译失败回滚已经确认的英文数据。

### 第三方插件耦合

风险：Magic 或 Translate for Zotero 更新后导致生词本失效，或意外读取其私密配置。

控制：

- AcademicVocab 不调用第三方插件未公开接口；
- 不读取第三方插件设置和密钥；
- 不抓取第三方插件界面中的翻译结果；
- 第三方插件禁用或卸载不影响 AcademicVocab。

### Zotero 人工标注被误删

风险：把颜色或文字相同的人工标注误认为插件标记。

控制：

- 不根据颜色、文字或位置猜测所有权；
- 删除操作必须匹配 AcademicVocab 本地所有权记录；
- 标记被用户修改、记录丢失或信息不一致时拒绝删除；
- 详细所有权和删除规则留到阶段 1D。

## 4. 最少日志规则

允许记录：

- 随机请求编号；
- 已验证用户的内部 ID；
- 成功、待处理、额度暂停或提供商错误状态；
- 本次字符数、累计项目字符数和耗时；
- 不包含正文的固定错误代码。

禁止记录：

- 腾讯 SecretId、SecretKey 或签名；
- 用户密码、会话令牌和设备凭据；
- 单词、例句、PDF 文件内容或私人论文标题；
- Supabase secret/service-role 值；
- 第三方完整错误响应。

## 5. 安全失败原则

发生以下情况时必须停止外部翻译调用：

- 无法验证用户或设备身份；
- 密钥缺失或配置异常；
- 后付费状态尚未由用户确认关闭；
- 项目月度字符上限已到；
- 请求疑似包含全文、文件或异常批量内容；
- 腾讯返回认证、计费或额度错误；
- 无法可靠判断重复请求。

停止翻译不等于丢弃生词。英文单词、例句和来源可以继续保存在待翻译状态。

## 6. 后续实施闸门

真正接入腾讯翻译前必须通过：

- Zotero 选词、标记所有权和 Android PDF 选词技术验证；
- 用户隔离测试；
- 客户端构建产物密钥检查；
- PDF 与全文不上传测试；
- 重复请求幂等测试；
- 额度边界和跨月重置测试；
- 断网、超时、腾讯异常与额度耗尽测试；
- 用户修订不被覆盖测试；
- 用户人工确认腾讯后付费关闭。

未全部通过时不得加入真实密钥。
