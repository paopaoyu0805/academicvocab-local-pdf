# 阶段 2：Zotero 选词弹窗人工验证

## 本阶段做了什么

本阶段建立一个零依赖、离线的最小 Zotero 插件，只用于确认 Zotero 9.0.6 的 PDF 选区弹窗能否满足产品需求。

它只会：

- 在 PDF 中选中文字后显示“AcademicVocab 验证”按钮；
- 临时显示选中的词或短语；
- 尝试从当前页面的本地文本层提取候选英文例句；
- 临时显示文件名、attachment key、parent item key、页码和选区位置；
- 允许临时修改单词和例句输入框，以验证未来界面。

它不会：

- 保存单词或例句；
- 联网或调用翻译；
- 创建、删除、覆盖或改色 Zotero 标注；
- 修改 PDF；
- 读取 Zotero SQLite 数据库；
- 访问日常 Zotero profile；
- 读取 Magic 或其他插件的设置。

## 开始前

1. 关闭日常 Zotero 和开发 Zotero。
2. 确认没有打开重要 Word 文档。
3. 只准备一篇不重要、没有私人内容的测试 PDF。
4. 测试 PDF 应位于：

   `D:\AcademicVocab\zotero-dev\test-pdfs`

## 启动

双击：

`D:\AcademicVocab\start-zotero-dev.cmd`

开发 Zotero 打开后：

1. 选择“工具 → 插件”；
2. 确认能看到 `AcademicVocab Selection POC 0.1.0`；
3. 确认它处于启用状态；
4. 如果看到了日常文献或正式账户，立即退出，不要继续。

## 基本测试

1. 在开发 Zotero 中打开测试 PDF。
2. 用鼠标选中一个英文单词。
3. 在 Zotero 自带选区工具旁寻找“AcademicVocab 验证”按钮。
4. 点击按钮。
5. 应出现标题为“AcademicVocab 选词弹窗技术验证”的窗口。
6. 检查：

   - “选中的词或短语”是否正确；
   - “候选英文例句”是否是包含该词的完整句子；
   - 文件名是否正确；
   - attachment key 是否不是“无法取得”；
   - 有父条目时，parent item key 是否正确；
   - 页码是否正确；
   - 选区位置是否显示 JSON 内容。

7. 临时修改单词或例句输入框。
8. 点击“关闭（不保存）”。
9. 再次选中同一处，确认刚才修改的内容没有被保存。

## 必测场景

请依次测试：

- 单栏 PDF 中的一个单词；
- 双栏 PDF 中的一个单词；
- 跨两行的短语或句子；
- 直接选中一整句；
- 连续打开和关闭弹窗三次；
- 按 Esc 或点击灰色背景关闭；
- 取消选择后确认没有新增 Zotero 标注；
- 退出并重启开发 Zotero，再测试一次。

如果暂时没有双栏测试 PDF，可以把这一项明确记录为“未测试”，不要使用私人论文代替。

## 如何判断没有修改 PDF 或标注

- 关闭弹窗后，Zotero 左侧标注列表不应新增任何内容；
- PDF 上不应出现新的高亮、下划线或颜色；
- 再次选中相同单词时，之前临时编辑的字段不应保留。
