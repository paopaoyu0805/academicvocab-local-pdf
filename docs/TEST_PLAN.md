# AcademicVocab 技术测试计划

## 1. 本阶段说明

本文只定义后续阶段的测试门槛。本阶段不创建代码、数据库、应用目录、测试数据或构建产物，不启动 Zotero、浏览器、Word 或云端服务。

任何技术验证失败时，必须停止在当前阶段，记录具体失败原因，不得通过放宽安全规则进入下一阶段。

## 2. 阶段 2：Zotero 选词弹窗技术验证

只在隔离开发 Zotero 中使用一篇不重要的测试 PDF，验证：

- 插件能加载、卸载和重启；
- PDF 阅读器中选中文字后能显示 AcademicVocab 小按钮或弹窗；
- 能读取用户实际选择的文本；
- 能提取候选英文例句，并允许用户确认或修改；
- 能取得文件名、attachment key、parent item key、页码和必要位置；
- 单栏、双栏和跨行选择分别测试；
- 重复打开和关闭弹窗不会残留多个界面；
- 取消操作不保存任何内容；
- 该阶段不联网、不翻译、不创建标记、不修改 PDF；
- 不访问日常 profile、正式资料库或私人 PDF。

通过标准：所有信息只显示在临时界面中，关闭后无永久改动；Zotero 重启和日常 Zotero 使用均不受影响。

验收记录：0.2.7 已于 2026-07-28 在隔离开发 Zotero 9.0.6 与受控测试 PDF 中通过；详细结果见 `docs\STAGE2B_SENTENCE_EXTRACTION.md`。

## 3. 阶段 3：Zotero 标记所有权技术验证

仍只使用隔离开发 Zotero 和测试 PDF，验证：

- 插件能创建一条真实的 Zotero 标注，而不是修改 PDF；
- 精确 annotation key 能写入本地账本；
- Zotero 重启后账本仍存在并能准确匹配；
- 同一捕获请求重复点击不会生成重复标记；
- 与人工高亮或下划线重叠时，只保存词句，不创建插件标记；
- 相同颜色、相同文字或相同位置的人工标注不会被误认；
- 用户改色、改批注、改标签或移动后，插件标记进入 `protected_modified`；
- 账本丢失或损坏后拒绝删除；
- 精确标记已不存在时，重复移除可安全完成且不寻找替代标记；
- 附件被移除或不可用时，不扫描其他附件；
- 模拟崩溃发生在“创建标注”和“写账本”之间时，遵守安全恢复规则；
- 模拟云端确认失败时，不会再次删除其他标注；
- 人工标注在全部测试中始终不被删除、覆盖或改色。

通过标准：只有本地账本和实际标注完全匹配的 AcademicVocab 标记能够被精确移除；所有不确定情况均保留标注并给出稳定错误。

## 4. Android PDF 选词技术验证

在后续独立阶段使用真实 Android Chrome 和不重要的本地测试 PDF，验证：

- PDF 只在手机本地打开，不上传云端；
- PDF.js 文本层可用；
- 单栏、双栏、跨行和分页附近的文字选择可用；
- 原生长按选择后能出现保存入口；
- 能取得单词、候选例句、文件标识和页码；
- 取消后不保存；
- 浏览器刷新或离线时不会上传 PDF。

如果 Android 原生文字选择不稳定，先报告真实失败场景，再单独评估自定义点击和拖动选择方案；不得在未验证前承诺体验。

## 5. 云端与自动翻译测试门槛

只有 Zotero 选词、Zotero 标记所有权和 Android PDF 选词三项技术验证都通过后，才允许连接云端和腾讯翻译。届时必须验证：

- 腾讯 SecretId 和 SecretKey 只存在服务端 Secrets；
- PWA、Zotero 插件、数据库、日志和 Git 中都没有真实密钥；
- 网络请求只发送确认后的单词和一条例句；
- PDF、全文和本地绝对路径从不上传；
- 用户级翻译缓存能防止重复计费；
- 每月 500000 字符内部硬上限由服务端原子执行；
- 达到上限后停止调用并返回 `TRANSLATION_QUOTA_PAUSED`；
- 腾讯后付费保持关闭；
- 用户修改的翻译不会被机器翻译覆盖；
- 断网、超时、重复请求和服务商错误都不会重复保存或无限重试；
- 两个测试用户互相不能读取数据。

## 6. 后续每阶段共同检查

每个阶段结束前都必须：

- 运行 D 盘路径检查；
- 确认没有指向 C 盘的项目路径、符号链接或 junction；
- 扫描真实密钥、密码、访问令牌和私人 PDF；
- 只运行该阶段适用的类型检查、lint、测试和构建；
- 更新 `docs\STATUS.md`；
- 使用 D 盘 Git 包装脚本创建提交；
- 人工验证项目没有影响日常 Zotero、Word 或正式资料库。
