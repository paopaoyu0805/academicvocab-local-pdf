# 项目决策记录

- 项目固定在 D 盘。
- 使用免费开源工具。
- 手机端优先采用 PWA。
- PDF 使用 PDF.js。
- 云端使用 Supabase 免费方案。
- 电脑端使用 Zotero 插件。
- 原始 PDF 永远不由本项目修改。
- 手机号登录不属于第一版。
- PDF 文件第一版不上传云端。
- 产品第一版只供用户本人使用，Android PWA 优先。
- 单词释义和例句中文翻译默认自动生成，用户只在需要时修改。
- 自动翻译只发送用户确认收录的单词和单条例句，不发送 PDF 或全文。
- 自动翻译计划使用腾讯机器翻译，但只能在后付费关闭、密钥安全隔离和项目免费额度限制生效后启用。
- 腾讯翻译密钥不得进入 PWA、Zotero 插件、数据库、日志或 Git。
- Magic for Zotero 继续独立用于全文翻译，AcademicVocab 不读取其账号、密钥或未公开内部接口。
- 同一个规范化单词只保留一条记录，可以关联多个例句和多篇论文。
- 点击“不再复习”需要确认；确认后保留全部学习数据，并排队移除 AcademicVocab 明确拥有的 Zotero 标记。
- 例句保存和翻译前必须先在本地完成边界提取与置信度判断；低置信度、跨页或同词多次出现时要求用户点选确认。
- 无可靠完整句时只显示来源片段，不得把整页文字当例句或发送给翻译服务。
- 同一单词的多个候选例句允许由用户多选后一次录入；仍只创建一条单词记录，每条例句分别翻译、查重并保存。
- 用户确认多条例句后，应为每条已选例句中对应的单词位置分别创建 AcademicVocab 自有亮紫色下划线；不得标记未选候选，也不得修改原始 PDF 或人工标注。
- AcademicVocab 下划线可以与用户的整句人工标注重叠，但只能新增独立标记，绝不覆盖、改色、拆分、合并或删除人工标注。
- 一次明确确认保存为一个摘录批次；同批多条例句不虚增“再遇次数”。
- 已掌握词再次遇到时保留新例句和来源，显示“再遇批次／例句总数”，由用户明确决定保持已掌握或重新复习。
- Android PWA 的单词操作采用轻点取词，避免依赖夸克对 PDF.js 透明文本层不稳定的原生拖选。
- 标题中的词允许收录，例句使用完整标题行；无标点正文片段保留为低置信度片段，不得自动连接下一页的大写新块。
- 跨行排版断词在候选提取前恢复为一个规范单词，例如 `inter-` 与下一行 `national` 合并为 `international`。
- 生词主记录使用英语原形作为规范键；选中时的原文词形仍随例句保存，避免复数、时态和第三人称形式重复建立生词。
- 手机端首屏只加载选词界面所需的小型入口；PDF 引擎在首屏首次绘制后立即预热，相邻页文本在 PDF 打开后空闲预热，避免大依赖阻塞页面显示或首次点词。
- 候选面板必须在耗时的跨页例句提取和词形归一化之前先显示；后台词典失败不得让轻点取词表现为无响应。
- 手机端词形归一化使用入口内置的保守规则与小型不规则词表，不加载大型运行时词典；无法可靠判断时宁可保留原词，真实样本发现的漏项加入受测试保护的小型例外表。
