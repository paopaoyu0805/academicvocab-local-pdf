# 阶段 2B：本地例句提取与置信度判断

## 1. 本阶段目标

本阶段只验证：在用户选中英文单词后，插件能否在本地提出有限、可解释的例句候选。

本阶段不会：

- 保存生词、例句或来源；
- 调用腾讯翻译或其他网络服务；
- 创建、删除、覆盖或改色 Zotero 标注；
- 修改 PDF；
- 读取日常 Zotero profile 或正式资料库；
- 读取 Magic 或其他第三方插件。

## 2. 本地处理流程

1. 读取选区所在页，以及最多一张前页和一张后页。
2. 只在内存中规范空白、行尾断词、页码和重复页眉页脚。
3. 在当前页寻找所选单词或短语的所有出现位置。
4. 优先寻找带 `. ! ?` 终止标点的完整句。
5. 分号默认保留在完整句内部；只有没有终止标点时才退回当前行片段。
6. 当前页开头或末尾明显是续句时，尝试与相邻页拼接。
7. 同词出现多次时显示最多三个不同候选，不擅自决定具体一次。
8. 候选超过 1000 字符时拒绝使用整段，退回所选文字。

页面文本不会进入日志，不会写入磁盘，也不会发送到网络。

## 3. 置信度

- `高`：当前页只有一个匹配，并取得正常结束的完整句；可以作为默认候选，但本阶段仍只预览。
- `中`：跨页拼接、同词多次出现、异常句首或较长句；必须由用户点选确认。
- `低`：没有可靠终止标点、只能取得一行来源片段，或所选文字无法在页面文本中定位；不得自动进入未来的保存和翻译流程。

“需要确认”只要求点选候选或修改英文内容，不要求用户手动翻译。未来可以多选候选，但每条最终确认的英文例句必须作为独立请求进入翻译入口；整页和相邻页文本始终只留在本地内存。

## 5. 自动化验收

零依赖测试位于：

`tests\sentence-extractor.test.cjs`

必须全部通过：

- 完整句不包含相邻句；
- `Dr.` 等缩写不被错误切断；
- 分号不被默认当作句号；
- 无标点列表只返回当前行，不返回整页；
- 跨行和连字符可以恢复；
- 跨页结果标记为中置信度并要求确认；
- 同词多次出现时保留多个候选；
- 重复页眉页脚和独立页码被过滤；
- 候选永不超过 1000 字符；
- 受控 PDF 的跨页和双栏文本顺序符合预期。

## 6. 人工验收

在隔离开发 Zotero 中安装 `AcademicVocab Selection POC 0.2.7` 后：

1. 导入并打开受控测试 PDF。
2. 依次选中 `Perforin`、`granzyme`、`antigen`、`international`、`Cytokine` 和第 2 页的 `stronger`。
3. 检查弹窗是否显示置信度、内容类型和候选按钮。
4. 无标点内容必须显示为“来源片段”，不能出现整页文本。
5. 第 2 页 `stronger` 应得到跨页完整句，并显示中置信度、需要确认。
6. 同词多次出现时应出现多个候选按钮，点击后只切换临时输入框。
7. 关闭弹窗后不保留临时修改，不新增 Zotero 标注。
8. 重启开发 Zotero 后再测试一次。

复杂扫描版 PDF、OCR、任意版式的完美阅读顺序不属于本阶段。真实 PDF 若文本层顺序异常，必须降低置信度并允许用户确认，不能把整页自动保存。
