# AcademicVocab 安全架构

## 1. 本文范围

本文只确定系统边界和自动翻译的安全调用方式，不代表相关组件已经开发或开通。

当前阶段没有：

- 创建网页或 Zotero 插件代码；
- 创建数据库或 Supabase 项目文件；
- 配置腾讯密钥；
- 调用腾讯机器翻译；
- 上传 PDF、全文或用户数据。

## 2. 未来系统组件

AcademicVocab 由以下独立部分组成：

### Android PWA

- 在手机浏览器中打开本地 PDF；
- 在本地渲染 PDF 和文字层；
- 获取用户选择的单词、英文例句、文件名和页码；
- 不把 PDF 二进制或全文交给云端；
- 登录后只同步生词、例句、翻译和来源元数据。

### Zotero 插件

- 只在隔离开发环境中开发和测试；
- 从 Zotero 阅读器获取用户主动选择的文字和来源；
- 不直接读取或修改 Zotero SQLite 数据库；
- 不修改原始 PDF；
- 只创建和管理 AcademicVocab 明确拥有的标记；
- 不读取 Magic、Translate for Zotero 或其他插件的账号与密钥。

### Supabase

未来只使用托管免费方案，承担：

- 用户登录和身份验证；
- 生词、例句、来源、复习与同步元数据；
- Row Level Security 用户隔离；
- 接收已登录客户端的安全服务端请求；
- 保存 Edge Function 使用的服务器端 Secrets。

客户端不得包含 `service_role` 或其他能够绕过用户隔离的密钥。

### 腾讯机器翻译

腾讯翻译只负责：

- 把一个已确认收录的英文单词翻译为中文；
- 把该单词对应的一条英文例句翻译为中文。

它不得接收 PDF、整篇论文、Zotero 数据库、账号信息或标注集合。

### Magic for Zotero

Magic 继续作为独立的全文翻译阅读工具。AcademicVocab 不调用 Magic 未公开的内部对象，不读取其账号、购买信息、翻译结果缓存或服务密钥。

Magic 是否运行，不影响 AcademicVocab 保存和复习生词。

## 3. 选词与自动翻译数据流

未来的正常流程为：

1. 用户在手机或 Zotero 主动选择一个英文单词。
2. 客户端在本地提取一条完整英文例句。
3. 客户端显示单词、例句、论文名称和页码，等待用户确认收录。
4. 用户确认后，英文数据先以可恢复方式保存。
5. 已登录客户端向自动翻译入口发送最小请求。
6. 服务端验证身份、输入长度、语言方向、请求频率和免费额度。
7. 服务端先检查相同文本是否已有缓存。
8. 缓存未命中时，服务端使用保存在云端 Secrets 中的腾讯凭据请求翻译。
9. 服务端返回单词释义和例句译文。
10. 客户端保存机器翻译结果；用户以后可以修改。

翻译超时、断网或额度暂停均不能阻止英文单词和例句保存。

## 4. 自动翻译入口契约

未来只允许经过身份验证的客户端调用一个服务端翻译入口。

请求最少包含：

- 客户端生成的唯一请求编号，用于防止重复调用；
- 一个不超过 100 字符的英文单词或短语；
- 一条不超过 2000 字符的英文例句；
- 固定的源语言英文和目标语言简体中文。

服务端必须拒绝：

- 未登录或设备身份无效的请求；
- 空内容或超过长度限制的内容；
- PDF、Base64 文件、二进制数据或批量全文；
- 不支持的语言方向；
- 超过频率或项目月度上限的请求。

响应只包含：

- 请求编号；
- 单词中文释义；
- 例句中文翻译；
- 翻译提供商标识；
- `completed`、`pending`、`quota_paused` 或 `provider_error` 状态；
- 不包含任何服务器密钥或内部错误堆栈。

具体数据库字段、缓存表和同步冲突规则留到阶段 1C 设计。

## 5. 密钥边界

腾讯 `SecretId` 和 `SecretKey` 未来由用户亲自在 Supabase Dashboard 的 Edge Function Secrets 页面设置。

密钥不得：

- 写入 D 盘项目文件或任何 `.env` 文件；
- 发给 Codex；
- 写入 PWA、Zotero 插件或构建产物；
- 保存到数据库业务表；
- 出现在日志、报错、测试快照或 Git 历史；
- 从现有翻译插件配置中读取或复制。

本地开发在没有安全云端 Secrets 的阶段使用完全模拟的翻译结果，不使用真实密钥。

## 6. 免费额度保护

项目只允许在腾讯后付费关闭的前提下启用自动翻译。

除腾讯账户自身的免费额度外，AcademicVocab 还必须实施独立硬限制：

- 默认每个自然月最多向腾讯发送 500000 个字符；
- 单词、空格、标点和例句均计入项目用量；
- 用量检查和增加必须由服务端执行，客户端显示不能作为依据；
- 达到上限后停止外部调用并返回 `quota_paused`；
- 不自动购买资源包，不自动开启后付费，不降级到其他付费服务；
- 新月份开始后才允许重新使用当月额度。

同一腾讯账户还可能被其他插件使用，因此项目内部计数不能代替腾讯控制台中的后付费关闭设置。

## 7. 分阶段启用

自动翻译不能提前进入技术验证阶段：

1. 先验证 Zotero 选词弹窗；
2. 再验证插件标记所有权和可逆删除；
3. 再验证真实 Android 手机的 PDF 选词；
4. 三项通过后才建立云端用户隔离和翻译入口；
5. 最后由用户手动设置云端 Secrets 并执行小额度测试。

任何阶段失败时都保留英文生词流程，不允许为了自动翻译降低 PDF、密钥或费用安全规则。

## 8. D 盘开发边界

- 项目源码、文档、依赖、缓存、测试和构建结果固定在 `D:\AcademicVocab`。
- Node、npm、npx 和 Git 只能通过 D 盘包装脚本。
- 不主动向 C 盘写入项目内容。
- 云端 Secrets 只存在于未来的 Supabase 托管环境，不在电脑本地保存副本。
