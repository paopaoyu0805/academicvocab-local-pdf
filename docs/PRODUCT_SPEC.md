# AcademicVocab 产品需求

## 1. 产品目标

AcademicVocab 是一套个人使用的学术英语生词系统。它帮助用户在阅读论文时快速收集生词、保留真实例句和论文来源，并在手机上复习。

第一版优先支持 Android 手机网页（PWA）和 Zotero 电脑插件。它不是公开运营的多人产品。

## 2. 手机端

用户可以在手机上：

- 导入并阅读本地 PDF；
- 选择英文单词；
- 自动提取包含该单词的完整英文例句；
- 自动获得单词中文释义和例句中文翻译；
- 在翻译有误时手动修改，但不要求逐条填写；
- 查看单词、多个例句、论文名称和页码；
- 搜索、整理和复习生词。

PDF 只在本地浏览器中处理，第一版不把 PDF 或全文上传到云端。

## 3. Zotero 端

用户可以在 Zotero PDF 阅读器中：

- 选择英文单词并加入 AcademicVocab；
- 保存单词、完整英文例句、论文信息和页码；
- 同一个单词存在多个可靠候选时，允许勾选多条例句并一次录入；
- 自动获得单词释义和例句翻译；
- 为每条已选例句中对应的单词位置分别创建 AcademicVocab 专用高亮；
- 在已有相同单词时新增例句，而不是创建重复单词。

插件不得修改原始 PDF，不得覆盖、改色或删除用户人工创建的 Zotero 标注。

Magic for Zotero 可以继续独立用于全文翻译。AcademicVocab 不读取 Magic 的账号、购买信息、密钥或未公开内部接口，也不依赖 Magic 才能正常工作。

## 4. 自动翻译

自动翻译的目标是避免用户逐条填写单词释义和例句译文。

- 只翻译用户确认收录的单词和对应英文例句；
- 不发送整篇 PDF、整篇论文或 Zotero 数据库；
- 机器结果允许用户修改；
- 用户修改后的内容优先显示，且不得被后台重新翻译覆盖；
- 相同文本应复用已有结果，避免重复请求；
- 离线或翻译失败时先保存英文内容，之后再重试。

计划使用腾讯机器翻译。只有在完成后续安全架构、密钥隔离和费用保护后才允许接入。腾讯密钥不得进入网页、Zotero 插件、Git、数据库或日志。后付费必须关闭，超过项目免费使用上限时停止翻译，不能自动产生费用。

## 5. 生词与例句

- 同一用户的相同规范化单词只保存一条生词记录；
- 不同词形或派生词不自动强制合并；
- 一个单词可以有多个真实例句；
- 多选例句时仍只建立一条生词记录，每条已选例句分别保存、翻译并关联来源；
- 一个单词可以出现在多篇论文和不同页码中；
- 本地例句提取为高置信度时可作为默认候选；跨页、重复词或异常边界必须要求用户点选确认；
- 无法可靠得到完整句时只显示“来源片段”，不得把整页文字自动保存或发送翻译；
- 完全相同的例句和来源不得重复保存；
- 多选界面默认不全选，必须让用户明确勾选；可提供“全选”，但不能把未勾选候选录入；
- 例句、译文和来源始终允许用户查看。

## 6. 复习与“不再复习”

用户可以在手机上复习生词，并将单词设为学习中、暂停、已掌握或归档。

点击“不再复习”时必须先确认。确认后：

- 单词状态改为已掌握；
- 停止进入日常复习；
- 保留单词、释义、例句、译文、论文来源和复习历史；
- 为该单词的 AcademicVocab 专用 Zotero 标记创建待处理任务；
- 电脑关闭时任务继续等待，下次 Zotero 安全同步时再处理。

任何情况下都不能根据颜色或文字猜测标记所有者，也不能删除人工标注。

## 7. 第一版不包含

- PDF 或全文云存储；
- 扫描版 PDF 的 OCR；
- OpenAI API 或其他付费 AI API；
- 手机号登录或付费短信；
- 读取 Magic 或其他插件的私密配置；
- 手机系统内其他应用的全局划词；
- iPhone 优先适配；
- Apple App Store 或 Google Play 发布；
- 面向公众的多人运营功能。

## 8. 成功标准

第一版成功需要满足：

- Zotero 和 Android 手机均能可靠选词；
- 自动提取的英文例句可以查看和修改；
- 单词释义和例句翻译可以自动生成；
- PDF 不上传；
- 重复单词只增加新例句；
- 手机与 Zotero 最终看到一致的生词数据；
- 原始 PDF 和人工 Zotero 标注始终安全；
- 停止复习后只移除 AcademicVocab 明确拥有的标记；
- 免费额度耗尽时停止外部调用，不产生自动费用。
