# 阶段 4：本地生词保存与摘录批次技术验证

本阶段只验证离线、可序列化的数据行为，不接入 Zotero 界面、不写入 Zotero SQLite、不开启网络、翻译、云同步、PWA 或正式数据库。

实现位于 `zotero-selection-poc/local-capture-store.js`。它是一个存储无关的内存模型：调用方可在未来用获批的本地持久化方式保存其快照；本阶段自身不读写文件、PDF、Zotero 数据或网络。

## 已验证规则

- 同一用户的规范化单词只创建一条记录；不同用户彼此隔离。
- 每次明确确认都创建一个摘录批次；同批多例句仍只计为一个批次。
- 例句按单词、来源、页码和规范化句子去重；完全重复例句不会增加该批次的 `exampleCount`。
- 同一例句在不同页码出现时保留为不同的来源 occurrence。
- 已掌握单词再次遇到时继续保存新例句和批次历史，但保持 `mastered`，并要求明确选择保持已掌握或重新复习。
- 数据模型拒绝本地绝对路径和没有用户明确确认的例句；不接收 PDF 内容、全文或任何凭据。

## 非目标

本阶段没有实现实际磁盘持久化、正式 Zotero 保存、标记创建／移除、复习调度、翻译、云端同步或用户界面。它们不得因本原型而提前启用。
