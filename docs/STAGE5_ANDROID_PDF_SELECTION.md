# 阶段 5：Android 本地 PDF 选词技术验证

## 范围

本阶段创建一个仅用于隔离技术验证的 Android PWA 原型。它只允许用户通过浏览器文件选择器打开一个本地测试 PDF，并在 PDF.js 文本层中选择英文词或短语，显示候选英文例句和来源页码。

原型必须满足：

- PDF 只由浏览器的本地 `File` 对象读取；不上传、不建立网络请求、不保存 PDF 字节或全文；
- 不调用翻译、Supabase、Zotero、OCR、OpenAI API 或任何付费服务；
- 取消、关闭或刷新页面时不保存单词、例句、来源或 PDF；本阶段不使用 localStorage、IndexedDB 或服务端；
- 只用非重要的测试 PDF；不访问日常 Zotero profile、SQLite、真实文献或人工标注；
- 不实现正式生词保存、批次保存、复习、云同步、正式 Zotero 交互或发布。

## 验收标准

在真实 Android Chrome 和非重要本地测试 PDF 上人工验证：

1. 文件通过本地文件选择器打开，刷新页面后浏览器不会恢复该 PDF。
2. PDF.js 文本层可选择单词或短语；选词后显示选中的文本、候选英文例句与页码。
3. 跨行、双栏或跨页附近的异常候选明确要求用户确认，不自动当作可靠完整句。
4. 点击取消或刷新后没有任何保存结果；浏览器开发者工具中没有 PDF 上传或翻译请求。
5. 离线时，已打开的本地 PDF 的选词与候选显示仍可用；无法加载本地 PDF.js 资源时给出明确错误，不降级为上传。

## 完成边界

本阶段的自动检查限于 PWA 的静态代码、离线候选提取逻辑、路径检查、lint、测试和构建。Android 真机验收需要用户在设备上执行，未完成前不得宣称阶段通过，也不得开始云端、翻译或正式持久化。
